# DeepSeek V4 Pro 0813 AI 특별판 편집 브리프

## 주제와 중심 질문

2026년 8월 13일 DeepSeek가 정식 출시한 `DeepSeek-V4-Pro`를 다룬다. 사용자가
접한 `DeepSeek-V4-Pro-0831`이라는 이름은 공식 자료에서 확인되지 않았고, 공식 API
문서가 밝힌 현재 모델 버전은 `DeepSeek-V4-Pro-0813`이다. 날짜 숫자를 뒤집은 표기가
커뮤니티에서 유통됐을 가능성이 있으므로, 기사 첫 부분에서 혼동을 짧고 명확하게 바로잡는다.

중심 질문은 다음과 같다.

> 4월 공개 프리뷰에서 8월 정식판으로 넘어오며 무엇이 달라졌고, 개발팀은 에이전트
> 모델의 성능뿐 아니라 버전 고정, 비용, 공개 가중치 상태를 어떻게 읽어야 하는가.

## 제목과 도입부

다음과 같은 뉴스형 제목을 우선 검토한다.

> DeepSeek, 에이전트용 V4 Pro 정식 출시…공식 버전은 ‘0813’

`0831`이라는 비공식 표기를 제목의 주인공으로 만들지는 않는다. 첫 세 문단은
`무엇이 정식 출시됐나 → 에이전트 개발에 무엇이 달라졌나 → 0813은 API가 가리키는
현재 버전이며 호출명과 공개 가중치 상태는 별개라는 점` 순서로 쓴다.

## 확인된 사실

- DeepSeek의 2026년 8월 13일 공식 발표는 V4 Pro를 GA로 출시했다고 밝혔다.
- 앱과 웹에서는 Expert Mode로, API에서는 기존과 같은 `deepseek-v4-pro`라는 이름으로
  사용할 수 있다. 공식 발표도 모델 이름이 바뀌지 않았다고 명시한다.
- 공식 가격·모델 문서의 현재 버전 표기는 `DeepSeek-V4-Pro-0813`이다.
- V4 Pro와 V4 Flash는 reasoning effort를 `low`, `high`, `max`로 조절할 수 있다.
  간단한 작업, 일반 에이전트 작업, 복잡한 작업에 계산량을 달리 배분하려는 장치다.
- OpenAI Responses API를 기본 지원하고, DeepSeek는 Codex용 원클릭 설정을 함께
  안내한다. Anthropic API, 도구 호출, JSON 출력도 공식 지원 목록에 들어 있다.
- V4 Pro의 컨텍스트 길이는 100만 토큰, 최대 출력은 38만4천 토큰으로 안내된다.
- 4월 프리뷰 발표 기준 V4 Pro는 전체 1.6조, 활성 490억 파라미터의 MoE 모델이며,
  프리뷰 가중치와 기술 보고서가 공개됐다.

## 개발팀이 실제로 봐야 할 변화

### 1. 정식판의 초점은 에이전트 운용

벤치마크 순위만 나열하지 않는다. reasoning effort, Responses API, 도구 호출, 긴
컨텍스트를 묶어 `한 모델을 작업 난이도에 따라 운용하고 기존 에이전트 런타임에 연결하는
제품화`가 이번 GA의 핵심이라는 관점으로 설명한다. DeepSeek가 말한 production gains는
회사 주장임을 분명히 하고 독립 재현 결과처럼 쓰지 않는다.

### 2. 안정된 호출명은 고정 버전을 뜻하지 않는다

API 호출명은 `deepseek-v4-pro`로 유지되지만 공식 문서는 그 뒤의 실제 버전을
`0813`으로 표시한다. 따라서 재현성이 필요한 팀은 모델 별칭만 기록하지 말고 테스트 날짜,
공식 버전 표기, 프롬프트·도구 정의, reasoning effort, 샘플링 설정과 회귀 평가 결과를 함께
남겨야 한다. 제공자가 고정 버전 endpoint를 제공한다고 확인되지 않는 한 `0813`을 직접
호출할 수 있다고 쓰지 않는다.

### 3. 새 가격제는 ‘할인’만 보고 해석하면 안 된다

현재 V4 Pro 가격은 100만 토큰당 cache-hit 입력 0.003625달러, cache-miss 입력
0.435달러, 출력 0.87달러다. 2026년 8월 16일 16:00 UTC부터는 비혼잡 시간대가 각각
0.022달러, 0.66달러, 1.98달러이고 혼잡 시간대는 그 두 배다. `off-peak가 peak보다
50% 싸다`는 말은 현재 가격보다 싸다는 뜻이 아니다. 캐시 적중 입력 약 6.1배, 캐시 미적중
입력 약 1.5배, 출력 약 2.3배로 비혼잡 가격도 현재보다 오른다는 점을 계산해 설명한다.
서울 기준 적용 시각은 8월 17일 오전 1시다. 가격은 발행 직전에 공식 문서를 다시 확인한다.

## 공개 가중치에 관해 반드시 구분할 것

4월 24일 프리뷰는 분명히 open-sourced와 open weights를 발표했고 Hugging Face에
`deepseek-ai/DeepSeek-V4-Pro` 저장소가 있다. 그러나 이 저장소의 최신 커밋은 6월 22일
기술 보고서 갱신이며, 8월 13일 GA에 맞춘 `DeepSeek-V4-Pro-0813` 체크포인트나 커밋은
발행 시점에 확인되지 않는다.

따라서 다음처럼 쓴다.

- `V4 Pro 계열의 프리뷰 가중치는 공개돼 있다`는 확인된 사실이다.
- `0813 정식판 가중치가 새로 공개됐다`고 단정할 근거는 현재 없다.
- API에서 서비스되는 0813과 Hugging Face의 무접미사 공개 가중치가 동일하다고
  추정하지 않는다.

이 구분을 기사 한 절에서 쉽게 설명하고 같은 경고를 여러 차례 반복하지 않는다.

## 문체와 구성

`정정 기사`나 모델 사양표처럼 쓰지 않는다. 다음 흐름을 권장한다.

`DeepSeek의 GA 발표 → 에이전트 개발자가 체감할 변화 → 0813과 고정되지 않은 API
별칭 → 예상보다 큰 가격 변화 → 공개 가중치의 확인된 범위 → 도입 전에 할 세 가지`

전문 용어 앞에 구체적인 장면을 둔다. 예를 들어 간단한 분류는 low, 코드베이스 수정은
high, 복잡한 조사·검증은 max처럼 설명하되, 실제 비용과 품질은 팀별 평가가 필요하다고
덧붙인다. 벤치마크 표를 길게 옮기지 말고, 성능 주장은 DeepSeek 자체 평가라는 사실을
한 번만 명확히 밝힌다. 이전 피드백에 맞춰 전문성은 유지하되 문장을 짧게 쓰고 핵심을
첫 문장에 둔다.

마지막에는 개발팀이 바로 실행할 점을 세 가지 정도로 정리한다.

1. 기존 에이전트 회귀 평가를 0813 환경에서 다시 실행한다.
2. 모델 별칭 이외의 실행 조건과 공식 버전 확인 날짜를 함께 기록한다.
3. 8월 17일 한국시간부터 바뀌는 입력·출력 비용을 실제 캐시 적중률로 다시 계산한다.
